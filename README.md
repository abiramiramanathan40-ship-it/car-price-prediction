# Car Price Prediction using Machine Learning

## Objective
Predict car selling prices using machine learning regression techniques.

## Dataset Features
- Car_Name
- Year
- Present_Price
- Driven_kms
- Fuel_Type
- Selling_type
- Transmission
- Owner

## Target Variable
- Selling_Price

## Libraries Used
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Algorithm
- Linear Regression

## Evaluation Metrics
- MAE
- MSE
- R² Score

## Result
The model was trained successfully and achieved a good R² score for car price prediction.
